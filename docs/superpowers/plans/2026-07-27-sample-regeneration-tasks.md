# Sample Regeneration Tasks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable regenerating the PNG and SVG samples for one visualization with a dedicated task while retaining `task samples` for all five visualizations.

**Architecture:** Replace the current `samples` matrix with five explicit Taskfile tasks, each owning one visualization's two output commands and its `build` dependency. Make `samples` invoke those tasks as ordered commands, then document the targeted workflow in the samples README.

**Tech Stack:** Taskfile v3, Go-built `bin/codeviz`, existing checked-in sample configurations and outputs.
